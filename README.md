# Akwam TV (unofficial)
Android TV / Google TV webview app for https://akwam.ss and https://old.akwam.ss, with remote-control pointer and best-effort ad blocking. No affiliation with the websites. This branch is only for building APK and does not modify main.

Build: GitHub Actions > Build Akwam TV APK. Artifact: AkwamTV-Installable-APK (contains app-debug.apk).
